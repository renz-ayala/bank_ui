# Bank UI (Cliente Demo)

Interfaz web minimalista diseñada para visualizar y consumir de forma interactiva la arquitectura de microservicios financieros y su patrón BFF.

---

## Repositorios Relacionados

* **Backend / Microservicios:** [banking-ms](https://github.com/renz-ayala/banking-ms) (Contiene los servicios BFF, Clientes, Productos y Docker Compose).
* **Starter Criptográfico:** [greckrypto_starter](https://github.com/renz-ayala/greckrypto_starter)

---

## Importante: Despertar Instancias en Render

Al estar alojados en la capa gratuita de Render, los microservicios entran en modo de suspensión tras periodos de inactividad. **Antes de usar la Demo**, debe "despertar" los 3 servicios haciendo clic en sus enlaces y esperando a que carguen completamente (hasta dejar de ver la pantalla de carga de Render y observar la respuesta del servidor como *Whitelabel Error Page 404* o *HTTP ERROR 401*):

1. https://banking-ms-clients.onrender.com
2. https://banking-ms-products.onrender.com
3. https://banking-ms-bff.onrender.com

Una vez que las 3 URLs respondan en el navegador, el backend estará 100% activo y listo para recibir peticiones desde esta interfaz.
